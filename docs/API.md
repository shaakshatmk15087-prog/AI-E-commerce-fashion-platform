# API reference

Generated by `backend/scripts/gen_docs.py` from the running code. All paths are under the API host; JSON in, JSON out.
121 endpoints.
Authentication is `Authorization: Bearer <token>` from `POST /api/v1/auth/login`. Errors look like `{"error": "...", "details": {...}, "request_id": "..."}`. Money is integer minor units (paise).

| Auth | Meaning |
|---|---|
| public | no token needed |
| token | any signed-in, active user |
| stylist | stylist accounts only |
| admin | administrators only |
